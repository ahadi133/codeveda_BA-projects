# Predictive Modeling Portfolio

**Author:** Ahadi Nur

## Objective

Build and compare models that predict business outcomes, estimate value, forecast demand, and segment customers.

## Included Analyses

- **Customer churn classification:** compared classifiers and retained predicted probabilities for held-out customers.
- **House-price regression:** compared regression approaches and evaluated predictions against actual sale prices.
- **Time-series forecasting:** generated forecasts and error tracking for sequential data.
- **Customer clustering:** created cluster profiles to support segmentation.

## Included Artifacts

- Model-comparison CSVs, held-out churn probabilities, forecast errors, and cluster profiles.
- ROC/confusion-matrix, forecast, and prediction-versus-actual charts.
- `app.py` — Streamlit app entry point for demonstrating selected model outputs.

## Important Note

`.joblib` model files are kept locally and ignored by Git. Recreate them through `../predictive_modeling.py` when publishing a fully reproducible public repository.
