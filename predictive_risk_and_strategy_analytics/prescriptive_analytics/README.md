# Prescriptive Retention Strategy Analysis

**Author:** Ahadi Nur

## Objective

Compare retention scenarios and recommend how constrained outreach capacity should be allocated.

## Included Artifacts

- `l3_assumptions_register.csv` — transparent scenario assumptions.
- `l3_scenario_comparison.csv` — outcomes across candidate strategies.
- `l3_recommended_allocation.csv` — recommended targeting allocation.
- `l3_strategy_simulation.csv` — simulation-level detail.

## How to Use This Work

Treat the recommendation as a decision framework rather than a fixed rule. Update the assumptions with current campaign cost, capacity, conversion rate, and customer value before operational deployment.
