# Exploratory Data Analysis: Iris Dataset

**Author:** Ahadi Nur

## Objective

Profile the Iris dataset and identify the feature patterns that distinguish species.

## Key Findings

- Each species has 50 observations, creating a balanced comparison.
- Petal length and petal width are strongly related and provide clear separation for Setosa.
- Setosa has the smallest petal dimensions, while Virginica has the largest.

## Included Artifacts

- `iris_descriptive_stats.csv` — summary statistics by feature.
- `iris_histograms.png` — feature distributions.
- `iris_boxplots.png` — spread and outlier comparisons by species.
- `iris_scatter.png` — multivariate species separation.
- `iris_corr_and_counts.png` — correlations and category counts.

## Tools

Python, pandas, seaborn, matplotlib, and SciPy.
