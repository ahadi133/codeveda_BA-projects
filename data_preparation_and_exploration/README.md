# Data Preparation & Exploratory Analysis

**Author:** Ahadi Nur  
**Focus:** turning raw records into analysis-ready data and communicating the patterns that matter.

This section demonstrates the first stage of an end-to-end analytics workflow: quality checks, cleaning decisions, feature engineering, descriptive analysis, and visual exploration.

## Projects

### [Data Cleaning](data_cleaning/README.md)

Prepared social-media sentiment and Iris datasets for downstream analysis. The work includes duplicate and missing-value checks, consistent text labels, typed date fields, and a business-friendly positive/negative/neutral sentiment grouping.

### [Exploratory Data Analysis](exploratory_data_analysis/README.md)

Explored the Iris dataset through descriptive statistics, distribution plots, correlation analysis, and species-level comparisons. The supporting visuals make the analysis reproducible and easy to review.

## Reproducibility

`data_preparation_and_exploration.py` contains the workflow that generated the cleaned data and exploratory outputs. Source-dataset paths are environment-specific; update them before rerunning.
